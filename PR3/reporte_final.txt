🔍 ANÁLISIS DE RENDIMIENTO:

1. ALGORITMO RECURSIVO:
   - Complejidad: O(2^t) exponencial
   - Funciona para casos pequeños (t≤100)
   - Hace timeout para t≥1000
   - Sin optimizaciones, explora todo el espacio de búsqueda

2. ALGORITMO CON MEMOIZACIÓN:
   - Complejidad: O(t²) con cache eficiente
   - Evita recalcular subproblemas repetidos
   - Funciona eficientemente hasta t=10000
   - Usa memoria adicional para el cache

3. ALGORITMO DINÁMICO:
   - Complejidad: O(t) tiempo, O(t) espacio
   - Más eficiente en tiempo y espacio
   - Iterativo, sin riesgo de stack overflow
   - Solución bottom-up óptima

📈 CONCLUSIONES:
• El algoritmo recursivo puro es impracticable para casos grandes
• La memoización mejora dramáticamente el rendimiento
• La programación dinámica es la solución más eficiente
• Para este problema específico (m=4, n=9), siempre conviene usar solo tipo M
